# 💪 FitBot - Gym Assistant Chatbot

A complete, beginner-friendly Gym Assistant Chatbot that helps users calculate their BMI, provides personalized workout and diet recommendations, and stores user data in a SQLite database.

## 📋 Project Overview

FitBot is a Streamlit-based web application designed to assist gym-goers and fitness enthusiasts in their health journey. The application:

- Collects user information (name, age, height, weight)
- Calculates Body Mass Index (BMI)
- Determines body category
- Provides personalized workout recommendations
- Offers customized diet plans
- Stores user data for tracking progress

## ✨ Features

- **User-Friendly Interface**: Clean, modern UI with Streamlit
- **BMI Calculation**: Automatic BMI calculation and categorization
- **Personalized Plans**: Custom workout and diet plans based on BMI category
- **Database Storage**: SQLite database for storing user information
- **Input Validation**: Comprehensive validation for all user inputs
- **Professional Design**: Color-coded results and responsive layout
- **Error Handling**: Robust error handling to prevent crashes
